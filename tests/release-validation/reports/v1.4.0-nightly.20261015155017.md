## Verdict

**Do not ship `1.4.0-nightly.20261015155017` as is.** There is no critical and no GA-blocker, and every fix the last gate asked for is in the build. Two new majors and one unverifiable gate item hold it back:

1. **`brain-slot-4seq-shared-kv-overflow` (new, major): the #2692 fix missed the brain profile.**
   - **Cause:** `[profile.brain]` has no `--parallel`, so llama-server runs 4 sequences on one 65,536-cell pool (`total_slots=4`).
   - **Effect:** when in-flight decode tokens pass 65,536, **every** brain request gets a 500.
   - **Evidence:** seen at 16:40:20, where 17,058 + 16,650 + 15,681 + 17,239 = 66,628 and all 4 tasks got `send_error`. The killed continuation was shown to the user as the #2673 sentence. Reproduced 4/4 with 4 × 16.4k prompts at `n_predict 1500`.
   - **Why it gates:** this is last run's P0 class. PR #2708's list of profiles never mentions brain, so it was missed rather than excluded.
2. **`utility-qwen-structured-output-zero-facts` (new, major, silent).**
   - **Cause:** `thinking.py:104` skips the default `enable_thinking=false` for any request that carries `response_format`. A Qwen3/3.5 extraction slot therefore reasons through Hindsight's whole 4,096-token cap.
   - **Effect:** Hindsight logs "Output too long … dropping", and the op `completed` with 0 facts.
   - **Evidence:** ct150's natural state was **41/41 at 0 facts over 30 h**. On ct151, all ~17 extractions in the window with the Qwen model bound returned 0 facts.
   - **The exemption is wider than needed:** an explicit `enable_thinking=false` plus `json_schema` returns valid JSON on this template with no #2020 400.
   - **Who is exposed:** the `hal0-lite` bundle ships `qwen3.5-0.8b`. A default fresh install is not affected.
3. **Last run's gate item 2 (#2694/#2696) is verified only by reading the source.**
   - ct150 no longer has a fork-only quant or a `render_error` slot.
   - `0f6a7112` also **introduced** a minor bug: an OFFLINE slot with an empty binding and a stale `model_id` says "still serving" (`manager.py:2354-2370`, no liveness check).

Everything else is minor.
