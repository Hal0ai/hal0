## Verdict

**Ship `1.4.0-nightly.20261016003929`: there are no blockers.** All four items on the last gate are in the build. #2736 and #2739 hold live. #2727 holds on lane evidence: every stop by the new code finished in about 20 s. #2738 landed with its unit tests, but no live run exercised it. Verification found no critical defect and no new major. The one major (#2741) is an open P1 the operator has already accepted for v1.5.0, and none of the 34 still-failing probes is a fix that broke again. The verdict rests on the coverage stated below. A fresh install with `/dev/kfd` is still untestable, prod lanes did not run, and no Qwen or brain-sft model was staged, so four model-class probes were scored on `lfm2.5-2.6b` only.

**Release-note items (known, not blockers):**
- **#2741: `hal0/utility` and `hal0/brain` run on the agent model when their own slot is cold** (open P1, v1.5.0). This is reproduced live on ct150. Hindsight extraction (`hal0/utility`) and the steward (`hal0/brain`) were served by the 27B agent: the journal has 56 `passthrough:agent` decisions, and utility and brain never started. Responses are 200, and the rewritten model id in `dispatch.decision` is the only trace. **This affects upgraded GPU boxes with a bound agent, which is ct105's shape.** The brain half can occur on stock config whenever brain has been idle-reaped while agent is warm. A stock fresh install does not hit it (agent is model-less).
- **The upgrade *into* this build can still hang once.** The #2727 fix lives in the new code, so the outgoing `…200136` process can still stall to systemd's 90 s SIGKILL while it stops. ct150's upgrade did exactly that: 21:25:44 → 21:27:14, about 95 s down. All later stops on the new code were bounded at about 20 s. A stream still in flight when the bound fires gets an HTTP 500 instead of finishing.
- **#2734 memory work serialises with chat** (unchanged). On ct151, hal0/agent 8-token turns took 10–98 s behind Hindsight work on the single-sequence brain or utility, and the first brain-lane turns took 94–283 s.
