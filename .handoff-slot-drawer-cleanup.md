# Slot Drawer Cleanup — Rolled Back Changes

**Date**: 2026-07-20  
**Rolled back from**: `e3163605` → reset to `3ddd9f58` (pre-merge `origin/main` into `rework/p3-brain`)

## Changes Applied (then rolled back)

### 1. Fix `image_pin` save rejection (`src/hal0/slot_config/__init__.py`)

- Added `"image_pin"` to `TOLERATED_SLOT_CONFIG_KEYS` so PUT /config no longer returns "unknown slot config key(s): image_pin"
- Belt-and-suspenders fix — the field IS declared on `SlotConfig` pydantic model but the running backend may predate it

### 2. Hardware grid relabel & reorder (`ui/src/dash/slot-modals.jsx`)

- **Old order**: `device` → `NGL` → `THREADS` → `BINARY` → `image_pin` (mixed case)
- **New order**: `DEVICE` → `IMAGE` → `BINARY` → `THREADS` (all caps)
- Changed `image_pin` label to `IMAGE`

### 3. NGL moved to Model section

- NGL (GPU offload layers) removed from Hardware grid
- Inserted into Model section between `ctx_size` and `Template`
- Rationale: it's a model-load parameter, not a hardware constraint

### 4. Parallel + extra_args moved to Model section

- **Parallel** (continuous batching / `--parallel`) moved from Inference → Model
- **extra_args** (per-slot flag override) moved from Advanced → Model
- Model section now: Model picker → ctx_size → NGL → Template → Parallel → extra_args
- Advanced disclosure now only holds resolved command preview + provenance legend

### 5. Image status strip shows actual image ref + slot_id

- Shows `slot.actual_image || slot.image_pin || slot.image` instead of `"present"`/`"missing"`
- Appends slot ID (e.g. `#3`) so operator can correlate to owning slot
- Shows `—` when slot is not running (`slotButtonPhase(slot) !== "running"`)

### 6. Runner · binary shows resolved backend

- When `slot.binary` is empty, shows `auto · rocm` (or `vulkan`/`cpu`/`npu`) instead of `auto (from device)`
- Uses `deviceBackend(device)` for resolution

### 7. BINARY label renamed to Profile

- HW grid field label: `BINARY` → `Profile`
- Description: "runner image (RUNNER_IMAGES)" → "runner profile"
- Dropdown options are profile names, not binary/image names

### 8. Deployed to 143

- SCP'd `slot-modals.jsx` and `slot_config/__init__.py` to `/usr/lib/hal0/hal0-0.9.8/`
- Rebuilt dashboard (`npm run build`)
- Restarted `hal0-api`
