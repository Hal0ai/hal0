## Re-apply Steps

```bash
# Deploy to both boxes:
BOX_HOST=10.0.1.150  # or 10.0.1.143
rsync -avz --delete --exclude='.git' --exclude='node_modules' --exclude='__pycache__' \
  -e 'ssh -i ~/.ssh/thin-mint' /home/mint/hal0/ root@$BOX_HOST:/root/hal0-deploy/
ssh -i ~/.ssh/thin-mint root@$BOX_HOST \
  '/usr/lib/hal0/venv/bin/pip install --force-reinstall --no-deps /root/hal0-deploy/'
ssh -i ~/.ssh/thin-mint root@$BOX_HOST \
  'rm -rf /usr/lib/hal0/current/ui && cp -a /root/hal0-deploy/ui /usr/lib/hal0/current/ui && cd /usr/lib/hal0/current/ui && rm -rf dist && npm install && npm run build'
ssh -i ~/.ssh/thin-mint root@$BOX_HOST 'systemctl restart hal0-api'
sleep 3
ssh -i ~/.ssh/thin-mint root@$BOX_HOST 'hal0 doctor all'
```
