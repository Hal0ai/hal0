# docs/archive/

Historical, non-authoritative notes moved here to declutter the repo root.
Nothing under this directory is current documentation or a source of truth
for how hal0 works today — treat it as a dated snapshot of thinking at the
time it was written, not a spec to implement against.

## handoffs/

Dated session-dump notes (design scratchpads, bench results, migration
plans, etc.) originally kept at the repo root as `handoffs/`. They are
preserved here for historical reference and because some code comments
still point at them by path, not because they describe current behavior.
For current docs, see `docs/` (guides, reference, concepts) instead.
