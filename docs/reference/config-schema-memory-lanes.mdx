This is the memory-lanes part of the `hal0.toml` reference. The rest of
`[memory]` is in [Config schema](/docs/reference/config-schema/); the other
config files are in [Config schema: slot files](/docs/reference/config-schema-slots/) and
[Config schema: providers, profiles, stacks & agents](/docs/reference/config-schema-profiles/).

## `[memory.lanes]` LLM concurrency lanes

The global caps every memory LLM call shares, and the per-operation overrides
under `[memory.lanes.<op>]`. The engine reads these as its own
`HINDSIGHT_API_*` environment variables.

| Key | Type | Default | Constraints |
|---|---|---|---|
| `llm_max_concurrent` | int | unset | `1-32`. `HINDSIGHT_API_LLM_MAX_CONCURRENT` global cap. Unset follows the effective `[memory.graph].extraction_max_concurrent`, and the consolidation lane then takes one fewer (minimum 1) so retain and page refresh always have a permit. An explicit value is rendered as min(this, effective `[memory.graph].extraction_max_concurrent`) and every lane inherits it unchanged. |
| `timeout_s` | int | `600` | `30-3600`. Not rendered. Engine-wide timeout: `[memory.graph].llm_timeout_s` (`HINDSIGHT_API_LLM_TIMEOUT`); see [#3631](https://github.com/Hal0ai/hal0/issues/3631). |
| `reasoning_effort` | str | `"none"` | `HINDSIGHT_API_LLM_REASONING_EFFORT`. |
| `strict_schema` | bool | `false` | `HINDSIGHT_API_LLM_STRICT_SCHEMA`. |

The per-operation tables `retain`, `consolidation`, `reflect` and
`mental_model_refresh` sit under this one and are documented further down this page.

## `[memory.lanes.<op>]` output caps

`<op>` is one of `retain`, `consolidation`, `reflect`, `mental_model_refresh`.

| Key | Type | Default | Constraints |
|---|---|---|---|
| `max_concurrent` | int | unset | `1-32`. `HINDSIGHT_API_{OP}_LLM_MAX_CONCURRENT` for this op; unset falls back to `[memory.lanes].llm_max_concurrent`. Shared-model ops use the same ceiling. |
| `virtual_model` | str | unset | Optional per-op hal0 virtual model override (for example `hal0/utility` for a burst lane) instead of the shared `hal0/memory` alias. |
| `timeout_s` | int | unset | `30-3600`. `HINDSIGHT_API_{OP}_LLM_TIMEOUT`; unset falls back to `HINDSIGHT_API_LLM_TIMEOUT` from `[memory.graph].llm_timeout_s` (not `[memory.lanes].timeout_s`). |
| `reasoning_effort` | str | unset | Per-op `HINDSIGHT_API_{OP}_LLM_REASONING_EFFORT` override; unset falls back to `[memory.lanes].reasoning_effort`. |
| `strict_schema` | bool | unset | Per-op `HINDSIGHT_API_{OP}_LLM_STRICT_SCHEMA` override; unset falls back to `[memory.lanes].strict_schema`. |
| `max_completion_tokens` | int | unset; `consolidation` and `reflect` then render `8192` | `0-131072`; `0` leaves the engine uncapped. Rendered as `HINDSIGHT_API_CONSOLIDATION_MAX_COMPLETION_TOKENS` or `HINDSIGHT_API_REFLECT_MAX_COMPLETION_TOKENS`. Mental-model refresh runs through reflect, so the reflect cap bounds it; a mental model whose `max_tokens` is near the cap leaves no headroom, because the engine fails the call on `finish_reason=length` instead of truncating, and on a thinking model reasoning tokens count inside the cap. Setting it on `retain` (use `[memory.graph].extraction_max_tokens`) or on `mental_model_refresh` is refused |

## `[memory.lanes.reflect]` and `[memory.lanes.consolidation]` extra keys

| Key | Type | Default | Constraints |
|---|---|---|---|
| `[memory.lanes.reflect].wall_timeout_s` | int | `1800` | `60-86400`. Rendered as `HINDSIGHT_API_REFLECT_WALL_TIMEOUT`: the seconds the engine gives one reflect, and one knowledge-page refresh (which runs as a reflect), from start to finish. The clock includes time spent waiting for a language-model permit, so a refresh queued behind consolidation and retain needs headroom. The engine's own default is 300. |
| `[memory.lanes.consolidation].batch_size` | int | `4` | `1-32`. Rendered as `HINDSIGHT_API_CONSOLIDATION_LLM_BATCH_SIZE`: memories consolidated per language-model call (`1` means no batching). The engine's own default is 8, which can overflow the 8192-token output cap; a batch that overflows is split and retried, and what still fails is counted as failed. |
