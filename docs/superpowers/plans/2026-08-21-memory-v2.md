# Memory v2 (Bank Workspace) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the shipping Memory section (Overview · Graph · Tools) with the approved memory_v2 design: two sub-tabs (Overview · Bank) where the Bank workspace unifies fact list, filters, sources, ego/web graphs, inspector, and curation.

**Architecture:** Backend first — three small additions to the existing Hindsight passthrough router (`memory_admin.py`): a curate PATCH forward, a raised ego-depth clamp, and one new hand-written ranked/filtered fact-list endpoint reusing the existing `GraphCache` + `_memory_subgraph` salience math. Then UI plumbing (endpoints, hooks, window-global bridge, mock fixtures), then view-by-view port of the prototype JSX into `ui/src/dash/` under the window-globals contract, finally kill-list removal and e2e rewrite.

**Tech Stack:** FastAPI + httpx passthrough (Python, pytest), React 18 no-ES-imports dash modules (`.jsx` + `Object.assign(window, …)`), TanStack Query hooks in TS bridges, d3-force via existing `__hal0D3Force` global, Vite, Playwright e2e with route-table mock.

**Design source (read-only reference):** `/mnt/mintdev/resources/hal0/memory_v2_handoff/` — `README.md` is the authoritative spec; `prototype/*.jsx` is the code to port; `prototype/v2.css` is the style source. Mock caveats listed at the bottom of the README apply (topics→tags rename, per-fact `topic` field is primary tag, curation store is session-local in the prototype only).

- Produces:
  `GET /api/memory/banks/{bank_id}/units?q&tags&type&state&from&to&document_id&sort=recency|salience&limit=20&offset=0`
  → `{"items": [unit…], "total_matched": int, "next_offset": int|null}` where each unit is the upstream `/memories/list` row **verbatim** plus computed `"salience": float` and `"link_counts_by_type": {<upstream link type>: n}` (memory graph emits `temporal`/`semantic`/`entity` — do NOT hardcode a type set; count whatever appears; `entity` scores 1.0 via `type_weight`'s unknown-type floor).

This route builds its upstream params explicitly (all single-valued), so it's safe — but do NOT route tags upstream by comma-join if 0.8.5+ lands; that needs `multi_items()` + httpx list-of-tuples. def degree_by_node(graph: Any) -> dict[Any, tuple[int, float]]:
    """Node id → (degree, weighted_salience) over the undirected adjacency."""
    adj = adjacency(graph)
    return {
        nid: (len(nbrs), sum(w for _, _, w in nbrs))
        for nid, nbrs in adj.items()
    }

```python
_UNIT_TS_KEYS = ("mentioned_at", "date")  # 0.8.4 list rows carry no created_at


def _unit_ts(row: dict[str, Any]) -> str:
    for k in _UNIT_TS_KEYS:
        v = row.get(k)
        if v:
            return str(v)
    return ""


@router.get("/banks/{bank_id}/units")
async def bank_units(request: Request, bank_id: str) -> dict[str, Any]:
    """Ranked, filterable fact slice for the Bank workspace (memory_v2 ask #2).

    Upstream ``/memories/list`` only understands q/type/limit/offset, so tag,
    time-window and document filters plus salience ranking are computed here
    over a cached slab — same tradeoff as ``bank_subgraph``.
    """
    client = _client(request)
    _validate_segments({"bank_id": bank_id})
    qp = request.query_params
    sort = qp.get("sort", "recency")
    if sort not in ("recency", "salience"):
        raise UnprocessableEntity(f"invalid sort: {sort!r}", code="memory.invalid_query")
    limit = min(int(qp.get("limit", 20)), 200)
    offset = max(int(qp.get("offset", 0)), 0)

    # NOTE: build upstream params explicitly — the generic forward's
    # dict(query_params) collapses repeated params; if 0.8.5+ tags forwarding
    # is ever added here it must use multi_items() + list-of-tuples.
    src_params: dict[str, str] = {
        k: qp[k] for k in ("q", "type", "state", "document_id") if qp.get(k)
    }
    src_params["limit"] = "2000"
    listing = await _forward(
        client, "GET", f"/v1/default/banks/{bank_id}/memories/list", params=src_params
    )
    rows = listing.get("items") if isinstance(listing, dict) else listing
    if not isinstance(rows, list):
        raise EngineShape("memories/list returned no item list")

    tags = {t for t in (qp.get("tags") or "").split(",") if t}
    lo, hi = qp.get("from"), qp.get("to")
    kept = [
        r
        for r in rows
        if isinstance(r, dict)
        and (not tags or tags & set(r.get("tags") or ()))
        and (not (lo or hi) or _unit_ts(r) != "")  # window given: undated rows drop
        and (not lo or _unit_ts(r) >= lo)
        and (not hi or _unit_ts(r)[: len(hi)] <= hi)
    ]

    # salience + per-type link counts from the cached bank graph (45s TTL)
    cache_key = f"{bank_id}:memories::"
    graph = _GRAPH_CACHE.peek(cache_key)
    if graph is None:
        graph = await _forward(
            client, "GET", f"/v1/default/banks/{bank_id}/graph", params={"limit": "2000"}
        )
        _GRAPH_CACHE.put(cache_key, graph)
    adj = _sg.adjacency(graph)
    for r in kept:
        nbrs = adj.get(r.get("id"), [])
        counts: dict[str, int] = {}
        for _, link_type, _w in nbrs:
            counts[link_type] = counts.get(link_type, 0) + 1
        r["link_counts_by_type"] = counts
        r["salience"] = sum(w for _, _, w in nbrs)

    kept.sort(
        key=(lambda r: (-r["salience"], _unit_ts(r)))
        if sort == "salience"
        else (lambda r: _unit_ts(r)),
        reverse=(sort == "recency"),
    )
    page = kept[offset : offset + limit]
    nxt = offset + limit if offset + limit < len(kept) else None
    return {"items": page, "total_matched": len(kept), "next_offset": nxt}
```

Match error-class names to what the module actually exports (`EngineShape` etc. — see classes at `memory_admin.py:58-95`); align the cache key format with `bank_subgraph`'s (`f"{bank_id}:memories:{type}:{q}"` with empty strings) so the two routes share cache entries.
